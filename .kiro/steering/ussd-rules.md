# USSD rules
- Every screen, menu options included, is 160 characters or fewer.
- Input is only digits, * and #. 0 = back, 00 = home.
- Each screen is CON (waiting for input) or END (session closed).
- Invalid input shows "Invalid choice. The spirits are confused." and repeats the menu.
- Long answers are split into pages ending with "1.More 0.Back".
- Main menu: 1 Ask the Oracle, 2 Quiz Me, 3 Exam Survival, 4 Explain Like I'm 5, 5 My Haunt Score, 0 Exit.
- Exit shows END "The line goes dead... Goodbye."
